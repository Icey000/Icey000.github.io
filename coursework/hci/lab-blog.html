Building a personal course portfolio

Local site prepared · online publication pending

Objective

Create a blog where lecture homework and practical work can be read online, including explanations of the process.

Approach

The website was prepared with AI assistance. It began as a small HCI course blog, then expanded into a personal website for Mingyu Zhang, with About, Projects and Coursework as the main sections. The HCI course keeps its own HW1–HW4 and Labs navigation.

Content and design decisions

The site is in English. Assignments are organised by homework number rather than by a separate list of concepts. HW1 contains six illustrated cases, each connected to the relevant task, with sources and proposed improvements. Reference material is distinguished from personal observations.

The personal site has its own project folder. Its publishable files are separated from the original lecture documents and local editing instructions, so the website can grow to include other courses without turning the HCI material folder into the public site.

Editing approach

The current static prototype includes a small local editor for changing article text and adding screenshots. It saves a downloadable HTML file. For longer-term visual authoring, Publii is being considered: it provides a desktop writing interface and generates a static website. The current files have not yet been migrated into a Publii project.

Publishing plan

GitHub Pages is the planned host. A first upload can be made through the GitHub website without GitHub Desktop. The actual repository, deployment settings and public URL will be recorded after publishing.

Remaining checks

  • Review draft content and add the required personal observations.
  • Choose the long-term authoring workflow before making regular updates.
  • Publish and open the site in a signed-out browser.
  • Check navigation, images and the direct HCI course link.
